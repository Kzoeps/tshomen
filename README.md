# Meridian

A local Mermaid diagram workspace built with React and Vite. Paste Mermaid source into the editor and see a live preview without sending your diagrams anywhere.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Features

- Multiple diagrams in tabs
- Live Mermaid preview with readable syntax errors
- Local persistence in `localStorage`
- Copy source, export SVG, and export PNG, including diagrams with multiline HTML labels
- 10–1600% cursor-centered zoom, drag-to-pan, fit-to-view, 1:1 size, and fullscreen preview
- Keyboard-accessible tab and editor controls

Everything runs in the browser. There is no server or diagram upload.
